# Orbit: source-linked workflows and automated tests

Keegan Balcerzak

## What Orbit does

Orbit is a personal desktop application that combines tasks, calendar events, recruiting actions and course deadlines. It uses React, TypeScript and Electron.

## My contribution

I worked on Orbit's React and TypeScript interface and the integration of these workflows. I also added source-linked status and automated tests for workflow records.

## Why source-linked status matters

A task's status is more useful when it connects back to the information behind it. A record marked complete and the source supporting that status are different pieces of information. Keeping them connected helps someone review the record rather than relying only on a summary label.

Orbit brings that source context into the workflow alongside the tasks and dates. Automated tests help check the workflow records as the application changes.

## What this demonstrates

The project combines a desktop interface, several related workflows, traceable status and automated testing. My work spans React and TypeScript implementation and checking application behavior.

## Scope and access

Orbit is a personal project. Its repository is private. This write-up describes the application and my contributions without exposing its code or private records.
